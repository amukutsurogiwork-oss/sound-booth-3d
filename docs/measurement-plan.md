# 完成後に測ること

ブースができたあとに、本当の遮音と換気を確かめるための一覧です。

**大事な注意**: 今の「21〜27dB」は、材料と計算からの**推定**です(実測ではありません)。完成後の実測と比べるための目安として使います。

## 1. 測ること

### 遮音 (外で聞こえる歌声の大きさの差)
- 中の音と外の音の差(dB)を、125 / 250 / 500 / 1k / 2kHz と、歌声全体(A特性)で測ります。
- 外の測る位置: 正面・横・背面、どれもブースの壁から 1m。
- 下の階: 真下の部屋の天井近く(聞こえ方と、足踏みの振動も)。

### 換気
- 扉を閉めて人が入ったまま、**中の CO2 濃度と温度**が時間でどう上がるかを記録します(0・5・10・15分)。
- ファンあり・なしを比べます。

### 扉の閉まり
- 扉まわりのすき間の幅と、パッキンが全周で当たっているか。
- 光を中から当てて、外にもれる所がないか(暗い所で)。

## 2. 測り方

### 簡単な方法 (スマホの騒音計アプリ)
1. 中で一定の音(ピンクノイズ、または一定の声「あー」)を出す。
2. 中央で音の大きさを測る。
3. 外の各位置(壁から 1m、同じ高さ)で、同じ音のまま測る。
4. 中と外の差が遮音(dB)。3回測って平均する。

### 限界
- スマホのマイクは低音(125Hz 付近)と大きな音が苦手で、数値が数 dB ずれます。
- 帯域別(125〜2kHz)は、専用アプリがないと測れません。その場合は「全体のA特性」だけにします。
- 周りの暗騒音が大きいと、小さな漏れは測れません。静かな夜に測る。
- 正確な値ではなく、推定との**だいたいの比較**として使います。

## 4. 安全

- 息苦しさ・暑さ・頭痛・めまいを感じたら、**すぐ扉を開ける**。
- 換気の測定は短く(15分まで)。長時間の連続使用はしない。
- 一人で長く入らず、近くに人がいる所で測る。
- 大きな音を出すときは耳を守り、近所への音にも気をつける。
